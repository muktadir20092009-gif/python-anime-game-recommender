# Anime Game Recommender

This is one of my first Python projects.

A command-line Anime and Game Recommendation App built with Python and JSON.

## Features

- Anime recommendations
- Game recommendations
- Search by genre
- Add new anime/game
- Remove anime/game
- History tracking
- JSON data storage
- Add favorite anime/game
- Remove favorite anime/game
## Technologies Used

- Python
- JSON
- File Handling
